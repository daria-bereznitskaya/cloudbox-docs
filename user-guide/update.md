# Обновление CloudBox


Эта инструкция относится к CloudBox версии 4.8 и выше. Проверить текущую версию можно в разделе **Настройки** → **О программе**.
Для проверки и загрузки обновлений требуется подключение к интернету. Если подключения нет, появится сообщение: `Не удалось проверить наличие обновлений. Проверьте подключение к интернету и повторите попытку.`

## Windows и macOS
### Проверка наличия обновлений
По умолчанию приложение проверяет наличие обновлений при его запуске. Чтобы проверить наличие обновлений вручную:
1. Откройте **Настройки**.
2. Выберите **О программе**.
3. Нажмите кнопку **Проверить обновления**.
### Скачивание обновлений
Если обновление доступно, появится кнопка **Скачать обновление**. Нажмите её, чтобы начать загрузку.
> Обновление скачивается в фоновом режиме. Во время загрузки вы можете продолжать работать.
По окончании загрузки обновления необходимо перезапустить приложение. Для этого:
1. Вернитесь в **Настройки** → **О программе**.
2. Нажмите **Перезапустить сейчас**.
* > Если есть несохранённые изменения, перед перезапуском приложение предложит их сохранить: `You have unsaved changes. Save them before restarting?` Нажмите **Save and restart** для сохранения данных и перезагрузки приложения или **Cancel** для закрытия диалогового окна.
## Linux
Автоматическое обновление приложения не поддерживается. Чтобы обновить CloudBox, скачайте новую версию с сайта.
