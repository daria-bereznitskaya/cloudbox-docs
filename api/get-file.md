# Получение информации о файле
Возвращает идентификатор, название и размер указанного файла.

Для обращения к API используйте метод
```http
GET /v1/files/{fileId}
```

## Параметры пути
| **Параметр** | **Тип** | **Обязательный** | **Описание** |
|---|---|---|---|
| `fileId` | integer | Да | Положительный целочисленный идентификатор файла |

## Авторизация
Для выполнения запроса необходимо также указать токен авторизации в заголовке:
```http
Authorization: Bearer <token>
```

## Успешный ответ
При успешном выполнении запроса сервер возвращает HTTP-статус `200 OK` и тело ответа в формате JSON:

```json
{
  "id": 42,
  "name": "report.pdf",
  "size": 2048
}
```

### Поля ответа
| **Параметр** | **Тип** | **Описание** |
|---|---|---|
| `id` | integer | Идентификатор файла |
| `name` | string | Название файла |
| `size` | integer | Размер файла в байтах |

## Возможные ошибки
| **HTTP-статус** | **Описание** |
|---|---|
| 401 | Пользователь не авторизован |
| 404 | Файл не найден |
